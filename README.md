# Кейс-задача № 2: Стилистическое преобразование чисел и анализ даты рождения

1. **Последовательный ввод даты (`request_birth_date`)**:
   * Поэтапный запрос дня (1–31), месяца (1–12) и года.
   * Валидация корректности даты (учёт количества дней в месяцах, високосность февраля, проверка на даты из будущего).
2. **Определение дня недели (`get_weekday_name`)**:
   * Определяет день недели на русском языке (Понедельник — Воскресенье).
3. **Проверка на високосный год (`is_leap_year`)**:
   * Проверяет кратность года по общепринятому астрономическому правилу: `(year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)`.
4. **Вычисление текущего возраста (`calculate_age`)**:
   * Точный расчёт полных лет с учётом того, наступил ли уже день рождения в текущем году.
   * Автоматическое склонение числительных (`год` / `года` / `лет`).
5. **Стилистическое электронное табло (`render_scoreboard_date`)**:
   * Отрисовка даты в формате `дд мм гггг`.
   * Каждая цифра прорисована матрицей символов `*` (размер 5x7 точек) с пробелами между блоками, имитируя винтажный цифровой LED-экран.
